## 步骤 3：生成 Bundle

执行以下 PowerShell 脚本（注意修改版本号）：

```powershell
$targetDir = "D:\study\常量配置中心\Constant-Config-Center\target"
$version = "1.0.1"
$bundleDir = Join-Path $targetDir "bundle\io\github\dongxystdu\constant-config-spring-boot-starter\$version"
New-Item -ItemType Directory -Path $bundleDir -Force | Out-Null

$files = @(
    "constant-config-spring-boot-starter-$version.jar",
    "constant-config-spring-boot-starter-$version.pom",
    "constant-config-spring-boot-starter-$version-sources.jar",
    "constant-config-spring-boot-starter-$version-javadoc.jar"
)

foreach ($file in $files) {
    Copy-Item (Join-Path $targetDir $file) $bundleDir
    Copy-Item (Join-Path $targetDir "$file.asc") $bundleDir
    
    $content = [System.IO.File]::ReadAllBytes((Join-Path $targetDir $file))
    $md5 = [System.Security.Cryptography.MD5]::Create().ComputeHash($content)
    $sha1 = [System.Security.Cryptography.SHA1]::Create().ComputeHash($content)
    
    [System.IO.File]::WriteAllText((Join-Path $bundleDir "$file.md5"), [System.BitConverter]::ToString($md5).Replace("-", "").ToLower())
    [System.IO.File]::WriteAllText((Join-Path $bundleDir "$file.sha1"), [System.BitConverter]::ToString($sha1).Replace("-", "").ToLower())
}

if (Test-Path (Join-Path $targetDir "bundle.zip")) { Remove-Item (Join-Path $targetDir "bundle.zip") }
Compress-Archive -Path (Join-Path $targetDir "bundle\*") -DestinationPath (Join-Path $targetDir "bundle.zip")

Write-Host "Bundle 已生成：$targetDir\bundle.zip"
```

**验证 bundle 结构：**

```powershell
Add-Type -AssemblyName System.IO.Compression.FileSystem
[System.IO.Compression.ZipFile]::OpenRead("$targetDir\bundle.zip").Entries | Select-Object FullName
```

## 步骤 4：上传到 Central Portal

1. 打开 https://central.sonatype.com/publishing/deployments
2. 点击 **Publish Component**
3. 填写：
   - **Deployment Name**：`constant-config-spring-boot-starter-1.0.1`
   - **Description**：`常量配置中心 Spring Boot Starter 1.0.1`
   - **Upload Your File**：选择 `D:\study\常量配置中心\Constant-Config-Center\target\bundle.zip`
4. 点击 **Publish Component** 提交

---

## 步骤 5：等待校验

- 状态变化：`VALIDATING` → `VALIDATED`
- 校验时间：通常 1-5 分钟
- 校验内容：
  - pom 元数据（licenses、developers、scm、url）
  - 文件完整性（jar + sources + javadoc + pom + .asc）
  - GPG 签名有效性
  - 坐标与 namespace 匹配

**如果校验失败：**
- 状态变为 `FAILED`
- 查看错误信息，常见问题：
  - 缺 `.md5`/`.sha1` 校验和
  - 缺 `.asc` 签名文件
  - 目录结构不正确
  - GPG 公钥未在密钥服务器

---

## 步骤 6：发布

校验通过后：
1. 状态变为 `VALIDATED`
2. 右侧 **Publish** 按钮变亮
3. 点击 **Publish**
4. 状态变为 `PUBLISHING` → `PUBLISHED`

## 常见问题

### Q1: GPG 签名失败
**错误**：`Could not determine gpg version`

**解决**：在 pom.xml 中指定 GPG 可执行文件路径：
```xml
<executable>C:\Program Files\GnuPG\bin\gpg.exe</executable>
```

### Q2: 校验失败 - 缺校验和
**错误**：`Missing md5 checksum for file: ...`

**解决**：确保 bundle 脚本生成了 `.md5` 和 `.sha1` 文件

### Q3: 校验失败 - 目录结构错误
**错误**：`File path './' is not valid for file '...'`

**解决**：确保 zip 内部路径为 `io/github/dongxystdu/.../1.0.1/...`，而非扁平结构

### Q4: 公钥未找到
**错误**：`Public key not found on keyserver`

**解决**：重新发布公钥：
```powershell
gpg --keyserver keyserver.ubuntu.com --send-keys 8C868A24370E5082F5EDAC090509D7B369650C77
```
